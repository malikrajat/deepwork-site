Talk to the person who builds it

DeepWork is one person's project. There is no support desk, no ticket queue and no account to sign in to — just the three routes below, and a form that reaches the same inbox.

Three ways in

A bug, or a feature you would like ↗ Public, on the project's issue tracker — best when the answer would help someone else too. github.com/malikrajat/deepwork Help installing or using the app An installer, a reminder that will not stop, where your data lives. support@rajatmalik.dev Everything else Privacy requests, licensing, this website, press, or a question about the project. contact@rajatmalik.dev
The address to keep
contact@rajatmalik.dev

I read everything that arrives. I cannot promise a reply time: this is one person's project, not a support desk. There is no phone number for DeepWork and none is asked for — email is the route.

Leave a message

Please do not send passwords, keys or anything confidential. If you are reporting a security problem with this site, say so in the first line.

Pressing Send opens your email app with the message ready, so it travels through your own provider and is not stored on this site. If no mail app opens, use contact@rajatmalik.dev directly.

Your message is kept only to answer it — no mailing list, no marketing, no account. What happens to it.
