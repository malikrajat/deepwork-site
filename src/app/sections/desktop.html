Updates

It tells you, once, and then installs

DeepWork checks the public release list in the background on startup — never blocking the window, cached for six hours so it does not spend a rate limit, and reporting nothing back. A newer build shows up as a small pill beside the version, a system notification, and a card with one button.

  • ✓ Windows — the setup is downloaded with a progress bar and started; DeepWork closes behind it.
  • ✓ macOS — the disk image is downloaded and opened for you.
  • ✓ Linux — a .deb or .rpm goes to your installer, or an AppImage is made runnable and started.
  • ✓ A version you waved away with Later is not announced again.

One honest caveat: the Windows and macOS installers are not code-signed yet, so Windows shows “Unknown publisher” and SmartScreen may interrupt the first run. The repository documents exactly what that means and how to verify a build. The web app avoids the question entirely, because there is nothing to install.
