Stay focused without forgetting the basics

Deep work is not the only thing a long afternoon is missing. The water reminder is off until you switch it on, and when it is on it behaves like a question rather than a notification.

Every answer is a choice, not a field

The useful range for each setting is narrow, and a number you have to type is a number you can mistype. So the reminder offers the sensible ones and nothing else.

Today, on the dashboard

The card reads out the day against the target, how many drinks that is, when the last one was and what the reminder is doing next. + 500 ml logs a glass at the size you chose; Undo takes it back if you pressed it twice.

“{{ quote }}” One of the ten lines the water reminder rotates through.

Each drink is a row of its own, so the day’s total is a sum rather than a counter that can only go up — and the tally starts again at local midnight, not at UTC midnight.
